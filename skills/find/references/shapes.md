# Product shapes

Find looks across every shape, not only subscription software. Record the most likely shape on the problem (`shape`), using one of these values.

| shape | what it is | why it can win | demand numbers that fit |
|---|---|---|---|
| `plugin` | a plugin for a CMS or app platform with a public directory | the directory is a channel with built-in discovery | `active_installs_top`, `active_installs_sum`, `keyword_volume` |
| `extension` | a browser or editor extension | marketplace search and listing pages | `extension_users` (manual, from the listing), `keyword_volume` |
| `web_tool` | a small single-job web app | search traffic to a page that does the job | `keyword_volume`, `trend_change_pct` |
| `digital_product` | templates, kits, guides, datasets | one-time purchase, no ongoing support | `keyword_volume`, `sales_count`, `paid_review_count` |
| `agent_tool` | an API or MCP server an agent can call | agent tool directories and agent users | `keyword_volume`, `hn_stories_365d` |
| `saas` | recurring software with accounts | recurring revenue | `mrr_usd`, `keyword_volume` |

A problem can fit several shapes. Pick the one with the shortest path to a paying buyer through a channel with built-in discovery, and mention the runners-up in `summary`.

Every shape should be usable by people's personal agents as well as by people. When the job can be done end to end through an API or MCP surface, say so in `summary`; it strengthens the agent-tailwind case.
