## 3. Operating model — the three-track conveyor (two-week cells)

**Track 1 — Discover & Validate:** S0 seed → S1 source → S2 score → S4 teardown (finalists) → S5 demand gate. Only validated ideas graduate.
**Track 2 — Build & Iterate (one cell = two weeks):** Week A: build + launch (S6 → S11). Week B: mandatory iteration on the same product — no new build during Week B.
**Track 3 — Grow / Sell / Kill:** weekly portfolio verdict (S15).

**Portfolio rules:** live-product cap <3–4>; breakout-halt rule (default: $2k MRR + W4 retention ≥40% → all effort concentrates); kill windows start at *channel-live*, never build-done.

## 4. Maxims (non-negotiables — edit to yours, then obey them)

1. Agent-native by default — as architecture, not as a market filter.
2. Built with the compound-engineering loop.
3. Cheap to start; distribution before build.
4. **Demand before build — for *you*, not the category.** Competitor traction never counts. Crowded market (Wedge ≤3) → switch test: ≥3 competitor-paying humans commit.
5. Painkiller, not vitamin. No undifferentiated AI wrappers.
6. A named way to charge, from day one. ≥50% gross margin structurally (the margin-floor gate).
7. Sellable asset by design: owner-independent, documented, transferable, retention instrumented from v1.
8. Build toward a named buyer whose minimums you can realistically meet.
9. Data over opinion — every claim carries a dated, resolving link.
10. One metric that matters per product + W1/W4 cohorts; pre-set keep/kill thresholds; kill-first.
